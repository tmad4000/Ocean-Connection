# Ocean Connection

*Honoring the yearning*

A mobile-first web app for tracking your connection to the ocean and water. Built for those who feel that deep pull toward the sea—the longing that feels like romantic love, like missing a part of yourself.

## What This Is

- **Log Ocean Touches** — Record when you touched the water. Where, when, what kind, how it felt.
- **Track The Ache** — Honor the yearning between touches. Note its intensity, what it feels like.
- **Practices** — Rituals for when you're landlocked:
  - Wave Breathing — Breathe like the tide
  - Ocean Sounds — Listen to the water
  - Memory Journey — Guided return to a moment
  - Find Water — Locate water nearby
  - Journal — Write letters to the ocean
  - Visualization — Feel the water on your skin
- **Memories** — Revisit your ocean touches, held safe.

## Running Locally

1. Clone this repository
2. Serve with any local server:
   ```bash
   # Python 3
   python -m http.server 8000

   # Node (npx)
   npx serve

   # PHP
   php -S localhost:8000
   ```
3. Open http://localhost:8000 on your phone or computer

## Installing on Your Phone

This is a Progressive Web App (PWA). You can add it to your home screen:

### iOS (Safari)
1. Open the app in Safari
2. Tap the Share button (box with arrow)
3. Scroll down and tap "Add to Home Screen"
4. Name it and tap Add

### Android (Chrome)
1. Open the app in Chrome
2. Tap the menu (three dots)
3. Tap "Add to Home Screen" or "Install app"

## Generating Icons

Before installing as a PWA, you need icons:

1. Open `generate-icons.html` in a browser
2. Download the 192x192 and 512x512 PNG files
3. Save them as `icon-192.png` and `icon-512.png` in this folder

## Hosting

To use on your phone, you'll need to host this somewhere. Options:

- **GitHub Pages** — Free, just push to a `gh-pages` branch
- **Netlify** — Free tier, drag and drop deploy
- **Vercel** — Free tier, connect to GitHub
- **Your own server** — Any static file host works

## The Philosophy

> "The yearning is the flow of life, the flow of wisdom. The source from which the value of intellectual activity flows. The stream of life around which the rest of our life activities can orient."

This app doesn't try to fix the ache. It honors it. The longing for the ocean is not a problem to solve—it's a thread connecting you to something larger. When you can't touch the water, you can still tend to that connection.
